## atomic sentences
[[proposition]]al logic builds up *sentences* from *atomic sentences*. these are **logically irreducible** statements which can either be true or false. 
we can build up more complex sentences from atomic sentences by using [[logical connectives]]. there is **one** *unary* connective ($\lnot$), and **four** *binary* connectives ($\land,\lor,\to,\leftrightarrow$)
